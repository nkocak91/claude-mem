# Polar Kalkulation

Handy-App (PWA) für die schnelle Kalkulation der Unterhaltsreinigung inkl. Angebots-PDF.

## Nutzung
- `index.html` über einen Webserver öffnen (z. B. GitHub Pages oder Netlify).
- Auf dem Handy „Zum Home-Bildschirm“ wählen. Danach läuft die App auch offline.
- Daten werden nur lokal auf dem Gerät gespeichert.

## Rechenweg
- Std/Woche je Bereich = Fläche ÷ (Flächenleistung × Belagfaktor) × Turnus
- Mehrzeit: kein Aufzug +5 %, weite Wege zu Putzkammer/Abfall +5 %
- Std/Monat = Std/Woche × 4,33
- Unterhalt = Std/Monat × SVS (32 €) × (1 + 20 % bei Reinigung während Betriebszeit)
- Verbrauchsmaterial (nur wenn Polar beschafft): Pauschale oder Belegschaft × €/Person
- Glasreinigung und Sonderleistungen werden im Angebot je Durchgang/Ausführung ausgewiesen

Alle Werte sind unter „Einstellungen“ änderbar.
